# 🛒 買い物リストスクリーンセイバー (Shopping List Screensaver)
買い物リストをスクリーンセイバーのようにPC画面内に反射させ続ける買い物リスト管理アプリ
「スマホに買うものをメモしたのに、お店に着いたらメモを開くこと自体を忘れていた…」
そんな買い忘れの悲劇をなくすために開発されたお買い物管理アプリケーションです。

---

## ✨ 主な機能

1. **🛒 売り場別の自動フィルター（LabelFrame構造）**
   - アイテムを追加すると、「スーパー」「日用品・雑貨」「その他」の売り場ごとに自動で綺麗に枠分け。お店での導線に沿って迷わず買い物ができます。
2. **🔍 画面と連動するフィルター切り替え**
   - 画面上部のタブで「今見たい売り場」だけにリストを瞬間絞り込み。
3. **💥 フィルター連動型スクリーンセイバー & 3倍速暴走アラート**
   - アプリの絞り込み状態がそのまま全画面スクリーンセイバーに直結！
   - さらに「今日買うもの」は緊迫の🚨マークが付き、**通常の3倍の速度で画面を大暴れ**します。
4. **🔊 衝突サウンドエフェクト（SE）**
   - 文字が画面の壁にぶつかるたびにポンッと小気味いい音が鳴り、ユーザーへ「早く買いに行かなきゃ！」という心地よい焦燥感を煽ります。
5. **✏️ 直感的なインライン編集 & 🗑️ 安心のゴミ箱（復元機能付き）**
   - タスク名をダブルクリックするだけで、その場でサクサク名前変更が可能。
   - 間違えて消したものはゴミ箱から1クリックで元の売り場へ安全に復元。

---

## 🛠️ 技術的なこだわり（アーキテクチャ）

本アーキテクチャは、ハッカソン短期間での爆速開発と堅牢性を両立するため、**3層構造（クリーンアーキテクチャ設計）**を厳格に採用しています。

- **UI層 (`main.py`)：** Tkinterによる、引き算の美学を意識したスッキリとしたモダンレイアウト。
- **ロジック層 (`screensaver.py`)：** 全画面Canvasによる物理衝突エミュレート、アニメーションループ、OSベル音の制御。
- **データ層 (`todo_store.py`)：** JSONファイル (`todos.json`) とのI/O、日付計算、状態変更をすべて「純粋関数」としてカプセル化したデータマネージャー。
